# LAD Factory routing

Read [context/routing.md](context/routing.md) for the relevant instruction set.
LAD Factory uses the installed host adapter and pinned model profile.
For first installation, follow [SETUP.md](SETUP.md).
For a run, follow `prompts/setup.md` after installation.
Current assignments and evidence live in `run/current/`.

The Orchestrator owns canonical state. Stages own their assigned outputs.
Follow the target repository's applicable instructions and preserve user changes.
Do not add a runtime, queue, launcher, or generated controller.
